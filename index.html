Le Guide BudgetFlow

Prenez le contrôle de vos finances en 4 étapes simples.

🔐

1. Sécurité & Accès

Votre mot de passe est la clé de votre coffre-fort. Rien n'est envoyé sur internet — vos données restent exclusivement dans la mémoire de cet appareil.

⚡

2. Gain de temps

Cochez "Appliquer aux mois suivants" lors de la création d'un abonnement pour le répercuter jusqu'à décembre. Utilisez "Copier mois préc." pour reporter vos charges fixes sans effort.

📊

3. Analyse Automatique

Le tableau de bord et le graphique circulaire se mettent à jour instantanément pour afficher votre capacité d'épargne et le poids de vos charges fixes.

🔄

4. Transfert de données

Pour changer d'appareil, cliquez sur "Transfert" en haut. Copiez le code chiffré généré et collez-le sur votre nouvel appareil pour restaurer tout.
